# Alex — Portfolio

My personal portfolio site, showcasing work across games, VR, interactive installations and web.

🔗 **Live:** [alexgg.com](https://alexgg.com)

## Highlights

- Real-time 3D hero scene with React Three Fiber
- Filterable project grid and a project viewer with image and video gallery
- Every project has its own shareable URL
- Content is data-driven: adding a project means editing a JSON file

## Stack

React · TypeScript · Vite · React Three Fiber · React Router · Zustand · SCSS · Vercel

## Run locally

Requires Node 22.

```bash
npm install
npm run dev
```
